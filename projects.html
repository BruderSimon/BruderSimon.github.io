PDF Encryptor

/pdf/encrypt-tool

This tool encrypts a PDF directly inside the browser and exports it as a standalone HTML file that can later decrypt and open the document after the correct password is entered. This tool is works entirely in your local browser, so no data is uploaded anywhere. The output contains the protected PDF data plus the code needed to unlock it later

The protection relies on AES-256-GCM, a modern authenticated encryption standard, while the password is converted into an encryption key using Argon2id. That matters because passwords are usually weak compared to real cryptographic keys. Argon2id deliberately makes password guessing slower and more expensive, and the use of a random salt prevents precomputed attacks against reused passwords.

In practice, attackers are unlikely to break AES itself. The realistic threat is offline brute-forcing the password, since anyone with the encrypted file can try unlimited guesses on their own hardware. Weak passwords such as common words, names, or predictable patterns can fall quickly. Strong passwords or long random passphrases make this attack dramatically harder.

However, I do not gurantee any cryptographical soundness or what so ever. Use it on your own risk
